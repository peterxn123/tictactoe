A basic Tic-Tac-Toe game made with HTML, CSS and JS.
Made as one of my first JS projects to develop my JavaScript skills.
Features:

- Play with local multiplayer against your friend.
- Play against a computer.
  -> Within this, you can choose the difficulty of the computer you want to play against.
- Toggleable light or dark theme
- Clean, minimalist modern theming
- No fluff, just Tic Tac Toe.
